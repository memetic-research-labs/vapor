# Keyboard Shortcuts

All keyboard shortcuts in Vapor. Press `⌘ /` inside Vapor to see this list in the app.

## Dictation

| Shortcut | Action |
|---|---|
| `Fn` (hold) | Start dictating — speak into your microphone |
| `Fn` (release) | Stop dictating — text is committed to the editor |

> The Fn key is the **only** way to control dictation. Clicking the microphone icon shows a reminder toast.

## Compression & Clipboard

| Shortcut | Action |
|---|---|
| `⌘ ↩` | **Compress & Copy** — compress the text and copy the compressed version to clipboard |
| `⌘ C` | **Copy Original** — copy the original (uncompressed) text to clipboard. If text is selected, copies only the selection |
| `⌘ K` | **Copy & Clear** — copy the original text to clipboard, then clear the editor |

> `⌘ K` never loses your text. The original is always copied to the clipboard and saved to prompt history before clearing.

## Window Management

| Shortcut | Action | Scope |
|---|---|---|
| `⌃ ⌥ Space` | **Focus Vapor** — bring the Vapor window to the front and activate it | Global (works from any app) |
| `⌘ \` | **Toggle Compact / Full** — switch between the compact pill view and the full editor | In-app |
| `Escape` | **Minimize** — switch from the full editor to the compact pill view | In-app (full editor only) |

> `⌃ ⌥ Space` only focuses the window — it does not change the window size. Use `⌘ \` to toggle between views.

> The global hotkey can be customized in **Settings** (`⌘ ,`) under "Global Hotkey."

## Navigation

| Shortcut | Action |
|---|---|
| `⌘ Y` | **Prompt History** — open the history window to browse, search, and restore past prompts |
| `⌘ ,` | **Settings** — open the settings panel |
| `⌘ /` | **Keyboard Shortcuts** — show the keyboard shortcuts help window |

## Editing

| Shortcut | Action |
|---|---|
| `⌘ A` | **Select All** — select all text in the editor |
| `⌘ Z` | **Undo** — undo the last edit |
| `⌘ ⇧ Z` | **Redo** — redo the last undone edit |
| `⌘ V` | **Paste** — paste from clipboard into the editor |

## Menu Bar

All shortcuts are also accessible from the macOS menu bar:

- **Edit** — Undo, Redo, Copy Original, Paste, Select All
- **Actions** — Compress & Copy, Copy & Clear, Prompt History, Keyboard Shortcuts
- **Window** — Toggle Compact / Full, Minimize to Compact
